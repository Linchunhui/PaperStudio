# 翻译质量与矢量交付

## 语言准确性

保持主语、逻辑关系、比较对象、实验条件和结论强度。不要把方法描述改成建议，不增加原文没有的贡献评价。谨慎处理 significant、robust、efficient 等词；统计显著和普通形容词含义不同。

保留精确数字、符号、单位、区间和误差。公式正文解释可翻译，公式本体不能擅自改写。表头与图注需与图表内容保持对应；数字无法识别时保留原文并标明待核验。

术语表记录原文、译名和上下文，允许用户指定词汇优先。涉及多个含义时不能把全篇机械替换为单一译词。缩写首次出现可给全称，但不补原文中不存在且不确定的展开。

## 交付与可追溯性

记录输入 PDF 哈希、翻译器/模型/术语表版本、目标语言、生成时间和页映射。原 PDF 为不可变来源；译文是独立产物。页数一致只是第一版接受上传的条件，不足以证明内容一一对应，界面应允许回原文核对。

输出 SVG 使用 PDF 渲染器转换真实原页与译文页。保留矢量文字路径、公式和线条，并使用对应的可选文字层。高亮锚点须绑定 side、页码、原文件哈希和规范化矩形，不能将旧译文锚点贴到新版本。

扫描型 PDF、错误字体映射、缺字、译文溢出和未翻译页均应显式报告；保留可阅读原文，不能让单页失败变成整篇虚假成功。不声称图像中的文字已经翻译，除非实际执行并核验该步骤。

## 当前应用范围

此 skill 提供角色指令与质量约束。当前 BabelDOC 由固定参数的程序适配器执行，不接受论文内容提供的 shell 命令。若适配器尚未将该 skill 全文传给翻译引擎，不能声称引擎已经逐条遵循此 skill；仍应保留这些规则作为术语与产物验收依据。
