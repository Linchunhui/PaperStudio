# 原图、公式与交付

## MVP 当前输出

本应用返回 Markdown 文本供右侧摘要面板安全展示。`cards/summary/all` 指内容组织方式；不代表已生成 HTML 文件。无法嵌入原图时提供原图编号、页码与导读，并注明未载入。不得输出可执行脚本、事件属性、外部资源加载指令或自造文件链接。

## 具有 HTML 导出能力时

只有运行环境确实提供导出器并完成检查，才生成 `.cards.html`、`.summary.html` 或 `.brief.html`。一个文件应包含必要样式和授权图像资源；不依赖本机绝对路径。将用户文本、模型内容、标题和图注转义；外链限定为安全 HTTP(S)。

原图必须来自当前论文版本，记录页码/图号。不要用重新绘制的示意图替代原图而不标注；解释性重绘须单独说明。裁剪保留图例、坐标和单位，检查目标阅读尺寸下的清晰度，不按固定图数凑数。

数学公式使用可靠的数学排版，验证括号、上下标、负号、符号及变量定义。没有验证公式识别结果时保留原页入口并明确待核验。

核对三件事：资源真实存在且已内嵌；浏览器打开后可读、无溢出或遮挡；主张、数字和图像来源与原文一致。前两项通过不等于第三项通过。

## 矢量阅读与图片边界

阅读器的 PDF 原页与翻译页由 PDF 渲染器生成 SVG，保留文字路径、公式和矢量图形。原 PDF 中已有的扫描图/位图不会因为放进 SVG 就变为矢量；清晰度受原图分辨率限制。不要用低分辨率整页截图替代 PDF 页面。
