# PaperStudio 0.5.0

第一次使用无需配置模型：打开自编 PDF 示例即可阅读和记录。管理员可以在网页选择兼容 API、本地模型或 Codex，分别查看配置、运行组件、连接和实际调用状态。

- BibTeX / RIS / Zotero CSV 预览迁入；只保存文献元数据，不自动下载或调用模型。
- 项目成果 ZIP、HTML、Markdown、JSON、BibTeX 导出，默认只含自己的笔记。
- OCR / 文档、Diffusion LLM、VLM 多级项目模板。
- 独立只读演示、预制双语 PDF 与一分钟操作导览。
- 轻量镜像、完整目录镜像和可选 Codex 镜像；SHA256 校验的完整数据包。
- 中英文 README、升级说明、贡献指南、AGPL-3.0-only 许可及第三方/数据说明。

## 使用

下载 `compose.release.yaml`，保存为 `compose.yaml` 后运行 `docker compose up -d`。镜像为 `ghcr.io/linchunhui/paperstudio:0.5.0`，完整/Codex 变体为 `0.5.0-full`、`0.5.0-codex`；目前发布 Linux amd64。

从容器 `/data/bootstrap-token` 获取一次性初始化令牌。完整数据包由管理员在设置页主动载入，也可使用 full 镜像。

## 升级与验证边界

已有用户先停止服务，备份完整数据目录、`.env` 和 CLI 认证；继续挂载同一数据卷。不要覆盖原 `.env`。本版保留所有原始目录与个人资料；新增模型配置只在管理员主动保存后覆盖环境变量。

发布工作流须通过 Python/前端回归、Chromium 操作、实际容器启动/重启和全量数据包校验。真实模型质量、BabelDOC 复杂版式、ARM 原生镜像仍需实际环境验收。公开 Demo 使用自编预制内容，不代表真实论文分析结果。
