## 尚未完成的现场验证

当前受管预览环境无法启动 Python 虚拟环境的解释器，故本次未完成浏览器手势与视觉验收。后端在本地 Python 环境可启动并完成集成测试。未使用绕过预览限制的替代浏览器工具。

本机启动后，应按以下流程验收：

1. 打开默认“阅读与证据”双语 PDF 样本；左右均显示两页实际 PDF。
2. 在原文拖选一个词、一整句与跨行文字，添加笔记，刷新后核对引用、高亮和页码。
3. 在译文重复批注；放大至 150% 和 200%，核对 SVG 文字与高亮位置。
4. 编辑一条批注，未保存时尝试编辑另一条；原稿应保留并提示先保存。
5. 将论文关联另一个项目，核对笔记与阅读位置隔离；创建至少三级项目并回到父项目查看子项目论文。
6. 快速翻页后点击“读完，整理笔记”；阅读状态保持已读。无模型配置时保留笔记并提示配置，不显示伪造总结。
7. 配置模型后生成导读、各类粗读、选区摘要与笔记总结，对照页码和原文检查证据与幻觉。
8. 安装已验证的 BabelDOC 版本，用真实论文检查中文字体、双栏原文、公式、跨页段落和图表保留。翻译期间导入人工修订版，后台任务应报告冲突且保留人工版。

原 PDF 没有文字层时，本版只能查看页面；划词依赖预先 OCR。译文当前必须与原文页数一致，尚未提供跨页语义对齐。
