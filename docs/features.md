# 功能与依赖

| 功能 | 需要模型 | 额外条件 / 边界 |
| --- | --- | --- |
| PDF 阅读、划线笔记、多级项目 | 否 | 扫描件没有可选文字时需另做 OCR |
| 自编阅读示例 | 否 | 原文和译文已预制，非真实论文分析效果 |
| 重排阅读 | 否 | 使用解析缓存/文字层，复杂公式和图表保留原图 |
| BibTeX / RIS / Zotero CSV 迁入 | 否 | UTF-8、2 MiB、500 条，预览确认；只保存元数据 |
| 项目成果导出 | 否 | 当前有权访问的材料，默认只含自己的笔记；不含 PDF/密钥 |
| 完整历史索引 | 否 | 可选完整数据包；保留快照日期与待核验标记 |
| 在线论文发现 | 否 | HF/arXiv 网络可用；全网与部分媒体需配置搜索服务 |
| 原文选段翻译 / 双语重排 | 是 | 可用文字层与兼容模型；按需请求，不自动全文翻译 |
| PDF 版式对照翻译 | 是 | BabelDOC 及版面/字体资源；逐页发布结果，排版需实际验收 |
| 摘要、导读、总结、问答、对比 | 是 | 论文正文/所需证据可获取；显示覆盖与引用 |
| 公开只读 Demo | 否 | 独立静态文件，预制示例，不存账号、论文或密钥 |

模型设置中的“运行组件可用”只说明程序可用，不能证明账号权限、上下文容量、视觉能力或输出质量。真实模型调用测试使用短消息，不能替代复杂论文验收。

模板提供 OCR、Diffusion LLM、VLM 的研究问题和目录。实际论文清单、经核验的方法演进与评测对齐，作为后续可贡献的专题内容单独维护，不以关键词相似度冒充技术路线。
