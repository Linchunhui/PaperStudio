# 论文关系网络、阅读材料与反馈

2026-10-28：索引的「知识图谱」和阅读助手的「相关」共用关系网络。点击论文节点重新展开其邻域；显示所选节点之间所有达到阈值的已知连接，不限于中心连线。粗细按综合相似度增加，默认阈值 0.45；降低阈值或勾选「弱关联用虚线显示」可查看弱边。阈值只控制连线，不改变节点集合；未知分数永远不画线。支持 10/25/50/100 篇相近论文、缩放、平移、键盘 Enter/Space 和搜索。

阅读助手增加「相关」「评论」标签；评论暂为空。「解读」下方紧凑显示三篇接续阅读及相似理由。整个侧栏可以收起，桌面状态本地保存，重新展开保留草稿；移动端继续使用有焦点约束的工具面板。问答 Enter 发送、Shift+Enter 换行，输入法确认和长按重复不发送。

图谱分数直接采用附件最终分数：概览 30%；方向、问题、方法、文献关系各 15%；关键结果 10%。单项分数和有方向的引用边未提供，不能据综合分数推断具体方法相似或谁引用谁。「引用」「被引用」显示待补充，不显示假零条数。

`config/relations` 保存完整上三角矩阵：0–100 为百分位，255 表示未知，gzip 后 base64 编码。原始分数只有两位小数，打包逐项检查精度。`config/reading-cards` 的 64 个 gzip/base64 分片保存每条完整 JSON，包括来源、证据 ID、摘要和限制；manifest 用于按 ID 查找。两种文件均校验 SHA256。

为避免传输工具的消息体限制，大于 550,000 字节的 JSON 另以描述文件和 `.part-*` 小分片保存。加载器校验每片及完整内容的字节数、SHA256 后还原原始 JSON；同时兼容未分片文件。现有目录分片、关系分数、摘要和来源字段不变。

## 身份与展示

图谱 ID 不是 PaperStudio 数据库主键。摘要匹配只使用明确的图谱 ID、arXiv ID 或唯一论文 URL，不按同名直接覆盖。首次升级给 8,469 份材料找到现有稳定标识；另外 410 份独立保存来源元数据（不保证它们都是新论文，可能包含未核实的不同版本）。完整初始化得到 29,329 条目录记录，原有 28,919 条记录和 32,162 条来源明细均保留；原目录分片未改动。重复初始化不增加记录。

生成摘要通过独立 `reading_card` 字段返回，保留作者摘要和原有 embedding 文档哈希。搜索、推荐、收藏以及图谱相关论文列表展示生成摘要与阅读价值；实际搜索排序/个性化推荐理由单独显示。文字和公式走共享的安全 LaTeX 渲染。正文源文件的本地路径不发送到前端；这些材料不能充当已核实的逐页原文引用。

## 账户反馈和推荐

论文列表、阅读器及图谱提供 👍 / ☆ / 👎。点赞与踩互斥，收藏独立；状态按账户保存，相同公开论文跨页面共享规范标识。收藏在「我的论文库 → 我的收藏」查看。私有 PDF 的反馈读取仍检查论文访问权限，统计不暴露用户身份。

推荐使用本账户收藏、点赞、最近阅读论文作为种子，最多 8 篇，依次按 1.0、0.95、0.75 加权。已知正相似度召回候选，与现有方向、机构、作者、时间等排序合并，理由明确指出种子与最终相似度。踩掉的论文被排除；反馈变化使旧推荐分页失效。关系数据失败时保留原规则推荐和负反馈过滤。无额外模型调用，也不将其他账户阅读记录用作当前用户种子。

## API

均由现有会话鉴权和 CSRF 机制保护。

- `GET /api/relations/search?q=&direction=&limit=20`
- `GET /api/relations/graph?paper=arxiv_2607_04884&limit=50&min_score=0.45&include_weak=false`；也可用 `catalog_id` 或经权限检查的 `paper_id` / `project_id`。
- `POST /api/paper-feedback/batch`：`references` 最多 100 条，每项只能选一个标识。
- `PATCH /api/paper-feedback`：`reference` 加 `vote: -1|0|1` 和/或 `starred: boolean`。
- `GET /api/paper-feedback/starred?page=1&limit=24`

## 验证

两份原附件与打包结果逐条比较：10,360,703 个分数/未知值及全部 8,879 条阅读材料内容相等。隔离数据库验证原有所有记录的 JSON 哈希未变化，8,879 份材料均有展示入口。

示例 `arxiv_2607_04884`：50 篇邻居、阈值 0.45 时共 51 节点、868 条边，其中 828 条为邻居间连接，隐藏 407 条弱边。本机一次图谱读取约 0.56 秒，仅为开发环境抽查，不是生产性能承诺。

自动回归覆盖权限与跨账户隔离、原文/生成内容边界、未知/零分、非中心连线与阈值、反馈持久化及失效、焦点与收起、Enter/IME、图谱缩放/平移/键盘/异步竞争、公式与内容转义。此工作环境没有连接可用的用户浏览器，DOM 合约测试不替代实机视觉或触摸验收。未部署或重启用户服务；拉取代码后按原启动流程重启会自动载入材料。
